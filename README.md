# 🎲 백수톡 내기 · 미니게임

백수톡 친구들과 쓰는 내기·미니게임 웹 앱. 순수 HTML/CSS/JS (외부 라이브러리 없음).

**▶ https://anchirong9-arch.github.io/baeksutalk-games/**

## 탭 1 — 🎡 룰렛 · 사다리
- 참가자 이름 자유 입력 (쉼표 / 줄바꿈, 최대 12명) + 인원 프리셋
- **룰렛**: 감속 애니메이션 + 당첨 섹터 하이라이트 + 폭죽 효과
- **사다리**: 랜덤 사다리를 그리고 참가자별 경로를 순서대로 추적 → 하단 결과와 매칭
  (결과 목록을 직접 고치거나 "결과 자동 만들기"로 당첨/꽝 생성)

## 탭 2 — ⚡ 반응속도 테스트
- 초록색으로 바뀌는 순간 클릭 → ms 측정
- 성급한 클릭(초록 전)은 실패 처리
- 닉네임과 함께 **오늘의 랭킹**에 저장 (localStorage, 날짜가 바뀌면 새로 시작)

## 탭 3 — 🎲 주사위 · 동전 · 뽑기
- 주사위 1~100 (최근 기록 표시)
- 동전 앞/뒤 3D 플립
- 메뉴/야식 룰렛 (목록 직접 수정 가능)
- 벌칙 추천 랜덤 뽑기

## 메모
- 모든 기록은 브라우저 localStorage에만 저장됩니다. 서버·계정·전송 없음.
- 모바일/PC 반응형, 다크 + 네온 테마.
